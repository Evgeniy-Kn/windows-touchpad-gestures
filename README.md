# Windows Touchpad Gestures

**Русский** | [English](README.en.md)

Маленькая фоновая программа для Windows 10/11 с Precision Touchpad:

- **Три пальца вниз сразу сворачивают активное окно**, даже полноэкранное. Стандартный жест Windows сначала выводит окно из полноэкранного режима и только потом сворачивает.
- **Одним пальцем вверх/вниз у правого края тачпада меняется громкость.** Показывается обычный индикатор громкости Windows, курсор в это время стоит на месте.

Один файл на Python, сторонние библиотеки не нужны (только `ctypes`).

## Требования

- Windows 10 или 11, тачпад Precision Touchpad
- Python 3.10+ ([python.org](https://www.python.org/downloads/) или Microsoft Store)

## Установка

1. Скачай репозиторий (Code → Download ZIP) и распакуй в удобную папку.
2. Назначь жест: **Параметры → Bluetooth и устройства → Сенсорная панель → Расширенные жесты → «Провести тремя пальцами вниз» → Пользовательское сочетание клавиш** → нажми `Ctrl+Alt+Shift+M`.
3. Добавь в автозагрузку и запусти:
   ```powershell
   powershell -ExecutionPolicy Bypass -File install_autostart.ps1
   ```

Громкость у края работает и без шага 2.

## Проверка и настройка

```powershell
py touchpad_gestures.pyw --debug     # координаты пальцев и состояние края в консоли
py touchpad_gestures.pyw --selftest  # проверка логики края
```

В начале `touchpad_gestures.pyw`:
- `EDGE_X = 0.93` — с какой доли ширины тачпада начинается зона громкости;
- `STEP_Y = 0.05` — сколько высоты тачпада нужно провести на один шаг громкости (2%).

## Удаление

Удали ярлык «Жесты тачпада» из папки автозагрузки (`Win+R` → `shell:startup`) и заверши процесс `pythonw.exe` в диспетчере задач. Жест в Параметрах верни на стандартный.

## Ограничения

- Игры в эксклюзивном полноэкранном режиме могут сворачиваться некорректно.
- Окна, запущенные от имени администратора, программа не свернёт, если сама запущена без прав администратора.
- Работает только на Windows.
